## 🔴 严重问题修复方案

### 问题 1: 小模型未启用沙箱 + Web 工具暴露

**风险描述**:
```
Small models (<=300B params) detected:
- ollama/qwen2.5:7b-instruct (7B) @ agents.defaults.model.primary

Uncontrolled input tools allowed: web_fetch
Small models are not recommended for untrusted inputs.
```

**风险分析**:
- 使用 7B 参数小模型（qwen2.5:7b）
- 未启用沙箱隔离
- 允许访问 `web_fetch` 等不可控工具
- 可能导致提示注入攻击

**修复方案（三选一）**:

#### 方案 A: 启用沙箱 + 禁用 Web 工具（推荐）⭐

**适用场景**: 继续使用当前小模型

**操作步骤**:

1. **编辑 openclaw.json**:
```json
{
  "agents": {
    "defaults": {
      "sandbox": {
        "mode": "all"
      },
      "model": {
        "primary": "ollama/qwen2.5:7b-instruct"
      },
      "tools": {
        "deny": ["group:web", "browser"]
      }
    }
  }
}
```

2. **验证配置**:
```bash
docker compose exec openclaw-gateway bash -c "openclaw config get agents.defaults.sandbox"
docker compose exec openclaw-gateway bash -c "openclaw config get agents.defaults.tools"
```

3. **重启容器**:
```bash
docker compose restart openclaw-gateway
```

---

#### 方案 B: 升级到大模型（最安全）⭐⭐⭐

**适用场景**: 追求最佳安全性

**操作步骤**:

1. **更换模型提供商**:
```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "openai/gpt-4o-mini"
        // 或 "anthropic/claude-3-haiku"
        // 或 "google/gemini-1.5-flash"
      }
    }
  }
}
```

2. **设置 API Key**:
```bash
$env:OPENAI_API_KEY="sk-xxx"
# 或在 .env 中添加
OPENAI_API_KEY=sk-xxx
```

3. **重启容器**:
```bash
docker compose restart openclaw-gateway
```

---

#### 方案 C: 完全禁用小模型（保守方案）

**适用场景**: 暂时不使用 AI 功能

**操作**:
```json
{
  "agents": {
    "defaults": {
      "model": {
        "enabled": false
      }
    }
  }
}
```

### 问题 2: 飞书开放群聊 + 高级工具

**风险描述**:
```
Found groupPolicy="open" at:
- channels.feishu.groupPolicy

With tools.elevated enabled, a prompt injection in those rooms 
can become a high-impact incident.
```

**风险分析**:
- 飞书使用 `groupPolicy="open"`（开放群聊）
- 同时启用了 `tools.elevated=true`（高级工具）
- 恶意用户可通过提示注入执行高权限操作

**修复方案（强烈推荐）**:

#### 步骤 1: 修改为白名单模式

**编辑 openclaw.json**:
```json
{
  "channels": {
    "feishu": {
      "groupPolicy": "allowlist",
      "tools": {
        "profile": "full",
        "elevated": true
      }
    }
  }
}
```

---

#### 步骤 2: 配置白名单群聊

**获取群聊 ID**:
```bash
# 在飞书中查看群聊详情
# 群聊 ID 格式：oc_abc123...
```

**添加白名单**:
```json
{
  "channels": {
    "feishu": {
      "groupPolicy": "allowlist",
      "allowGroups": [
        "oc_你的受信任群聊 ID"
      ]
    }
  }
}
```

---

#### 步骤 3: 验证配置

```bash
# 检查配置
docker compose exec openclaw-gateway bash -c "cat /home/node/.openclaw/openclaw.json | grep -A5 feishu"

# 重启容器
docker compose restart openclaw-gateway

# 测试：在非白名单群聊中@机器人，应该无响应
```

### 问题 3: 飞书开放群聊 + 运行时/文件系统工具

**风险描述**:
```
Found groupPolicy="open" at:
- channels.feishu.groupPolicy

Risky tool exposure contexts:
- agents.defaults (sandbox=off; runtime=[exec, process]; fs=[read, write, edit, apply_patch]; fs.workspaceOnly=false)
```

**风险分析**:
- 开放群聊可访问执行命令、文件读写等高危工具
- 未启用沙箱隔离
- 文件系统不限工作区（可访问整个系统）

**修复方案（组合拳）**:

#### 步骤 1: 启用沙箱隔离

```json
{
  "agents": {
    "defaults": {
      "sandbox": {
        "mode": "all"
      }
    }
  }
}
```

---

#### 步骤 2: 限制文件系统访问

```json
{
  "tools": {
    "fs": {
      "workspaceOnly": true
    }
  }
}
```

**效果**: 只能访问 `/home/node/.openclaw/workspace/` 目录

---

#### 步骤 3: 移除或限制运行时工具

**选项 A: 完全禁用（推荐）**:
```json
{
  "tools": {
    "deny": ["group:runtime", "group:fs"]
  }
}
```

**选项 B: 仅允许特定工具**:
```json
{
  "tools": {
    "allow": [
      "exec",
      "fs.read",
      "fs.write"
    ],
    "deny": ["process.*", "fs.apply_patch"]
  }
}
```

---

#### 步骤 4: 使用 messaging 配置文件

**最简单的方式**:
```json
{
  "channels": {
    "feishu": {
      "tools": {
        "profile": "messaging"
      }
    }
  }
}
```

**效果**: 自动禁用所有高危工具，只保留消息相关功能

### 问题 4: 飞书插件包含危险代码模式

**风险描述**:
```
Plugin "feishu" contains dangerous code patterns
Found 2 critical issue(s):
- [env-harvesting] Environment variable access combined with network send
  (src/client.test.ts:74)
- [env-harvesting] Environment variable access combined with network send
  (src/client.ts:12)
```

**风险分析**:
- 插件代码读取环境变量并通过网络发送
- 可能是凭证窃取行为
- 需要人工审查确认是否恶意

**修复方案**:

#### 步骤 1: 审查可疑代码

**查看问题文件**:
```bash
# 进入容器查看
docker compose exec openclaw-gateway bash -c "cat /home/node/.openclaw/extensions/feishu/src/client.ts | head -20"

# 查看测试文件
docker compose exec openclaw-gateway bash -c "cat /home/node/.openclaw/extensions/feishu/src/client.test.ts | grep -A5 -B5 'process.env'"
```

---

#### 步骤 2: 判断是否可信

**检查要点**:
1. ✅ 网络请求是否发送到官方域名（open.feishu.cn）
2. ✅ 环境变量是否仅为必要的配置（如 App Secret）
3. ✅ 是否有异常的外发请求（到未知域名）
4. ✅ Git 提交历史是否正常

**如果代码来自官方仓库且版本匹配**:
- ✅ 可以信任，忽略此警告
- 这是正常 API 调用所需

**如果发现异常**:
- ❌ 立即禁用插件
- 从源码重新构建

## ⚠️ 警告问题修复方案

### 问题 1: 飞书文档创建可能泄露权限

**风险**: 创建文档时可能授予请求者权限

**修复**:
```json
{
  "channels": {
    "feishu": {
      "tools": {
        "doc": false
      }
    }
  }
}
```

**说明**: 如不需要文档功能，直接禁用

---

### 问题 2: 网关认证无限流保护

**风险**: 未配置认证频率限制，可能被暴力破解

**修复**:

**编辑 .env**:
```ini
# 添加频率限制配置
# 格式：maxAttempts/windowMs/lockoutMs
GATEWAY_AUTH_RATE_LIMIT=10/60000/300000
```

**或编辑 openclaw.json**:
```json
{
  "gateway": {
    "auth": {
      "rateLimit": {
        "maxAttempts": 10,
        "windowMs": 60000,
        "lockoutMs": 300000
      }
    }
  }
}
```

**效果**: 
- 每 60 秒最多尝试 10 次
- 失败后锁定 5 分钟

---

### 问题 3: 网关节点命令限制无效

**问题**: `gateway.nodes.denyCommands` 使用了无效的命令名

**修复**:

**编辑 openclaw.json**, 替换无效命令:
```json
{
  "gateway": {
    "nodes": {
      "denyCommands": [
        // 使用正确的命令名
        "canvas.present",
        "canvas.hide",
        "canvas.navigate",
        "canvas.eval",
        "canvas.snapshot",
        "canvas.a2ui.push",
        "canvas.a2ui.pushJSONL",
        "canvas.a2ui.reset"
      ]
    }
  }
}
```

### 问题 4: 多用户环境 heuristic 警告

**说明**: 这是设计特性，非真正的问题

**OpenClaw 设计理念**:
- 默认是"个人助理"模式（单一信任边界）
- 不是 hostile multi-tenant 隔离

**如果确实是多用户使用**:

1. **分离信任边界**（推荐）:
   - 每个用户独立 Gateway
   - 独立 OS 用户/主机
   - 独立凭证

2. **强化共享 Gateway**（折中）:
   ```json
   {
     "agents": {
       "defaults": {
         "sandbox": {
           "mode": "all"
         }
       }
     },
     "tools": {
       "fs": {
         "workspaceOnly": true
       },
       "deny": ["group:runtime", "group:fs", "group:web"]
     }
   }
   }
   ```
