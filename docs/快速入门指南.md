# OpenClaw 快速入门指南

> **5 分钟开始使用 OpenClaw**  
> **适用**: Windows + Docker Desktop 环境

---

## 🚀 一键部署（推荐）

### 前提条件

确保已安装：
- ✅ Docker Desktop for Windows
- ✅ PowerShell 7+

### 执行部署脚本

```powershell
cd E:\AI\openclaw_docker
.\scripts\deploy-openclaw.ps1
```

**脚本会自动：**
1. 检查环境
2. 创建配置文件
3. 启动容器
4. 验证服务

**完成后浏览器会自动打开 Control UI！**

---

## 📝 手动配置（可选）

如果自动部署失败，请手动配置：

### 步骤 1: 复制配置文件

```powershell
Copy-Item .env.example .env
notepad .env
```

### 步骤 2: 修改关键配置

在 `.env` 文件中修改：

```ini
# 必须修改为你的真实值
OPENCLAW_GATEWAY_TOKEN=你的网关令牌

# 可选（推荐配置）
GITHUB_TOKEN="ghp_你的 github_token"
```

### 步骤 3: 启动容器

```powershell
docker compose up -d

# 查看日志
docker compose logs -f
```

## 💬 配置消息信道

### 飞书（推荐）

1. **创建飞书机器人**
   - 访问 https://open.feishu.cn/
   - 创建企业自建应用
   - 添加机器人能力

2. **获取凭证**
   - App ID: `cli_xxx`
   - App Secret: `xxx`

3. **配置到 openclaw.json**
   
   编辑 `E:\AI\openclaw_docker\data\openclaw.json`:
   
   ```json
   {
     "channels": {
       "feishu": {
         "appId": "cli_xxx",
         "appSecret": "xxx"
       }
     }
   }
   ```

4. **重启容器**
   ```bash
   docker compose restart openclaw-gateway
   ```

5. **测试**
   - 在飞书中给机器人发送消息
   - 机器人应该回复

## 🔧 常用命令

```powershell
# 启动/停止
docker compose up -d           # 后台启动
docker compose down            # 停止并清理
docker compose restart         # 重启

# 查看状态
docker compose ps              # 容器状态
docker compose logs -f         # 实时日志

# 进入容器
docker compose exec openclaw-gateway bash

# 更新代码（热重载）
cd E:\AI\openclaw_docker\openclaw
git pull upstream main --rebase
# 等待 30 秒自动生效
```

## ❓ 常见问题

### Q: 容器启动后立即退出？

**A:** 检查 `.env` 中的 `OPENCLAW_GATEWAY_TOKEN` 是否配置正确。

### Q: Control UI 打不开？

**A:** 
1. 等待 1-2 分钟让服务完全启动
2. 检查防火墙设置
3. 尝试 `docker compose restart`

### Q: 飞书机器人不回复？

**A:** 
1. 检查 App Secret 是否正确
2. 确认飞书应用已发布
3. 查看日志：`docker compose logs openclaw-gateway | Select-String feishu`
