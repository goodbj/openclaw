## 前置要求

### 硬件要求

| 项目 | 最低配置 | 推荐配置 |
|------|----------|----------|
| **CPU** | 4 核 | 8 核及以上 |
| **内存** | 8GB | 16GB 及以上 |

### 软件要求

#### ✅ 必需软件

1. **Windows 10/11 (64 位)**
   - 版本：2004 或更高（Build 19041+）
   - 启用 WSL 2 功能

2. **Docker Desktop for Windows**
   - 版本：4.0 或更高
   - 配置：启用 WSL 2 后端
   - 下载：https://www.docker.com/products/docker-desktop

3. **Git for Windows**
   - 版本：2.30 或更高
   - 下载：https://git-scm.com/download/win

4. **Node.js（可选，用于本地开发）**
   - 版本：22+ LTS
   - 下载：https://nodejs.org/

## 快速开始

### 5 分钟快速部署

```powershell
# 步骤 1: 克隆仓库
cd E:\AI
git clone https://github.com/openclaw/openclaw.git
cd openclaw

# 步骤 2: 复制并编辑配置文件
```

## 详细安装步骤

### 步骤 1: 启用 WSL 2

**以管理员身份运行 PowerShell：**

```powershell
# 启用 WSL 功能
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart

# 启用虚拟机平台
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

# 设置 WSL 2 为默认值
wsl --set-default-version 2

# 重启电脑
Restart-Computer
```

---

### 步骤 2: 安装 Docker Desktop

1. **下载安装包**
   - 访问：https://desktop.docker.com/win/main/amd64/Docker%20Desktop%20Installer.exe
   - 双击运行安装程序

2. **配置 Docker Desktop**
   - 勾选 "Use WSL 2 instead of Hyper-V"
   - 选择安装路径（建议默认）
   - 点击 "OK" 开始安装

3. **首次启动配置**
   - 启动 Docker Desktop
   - 接受服务条款
   - 等待引擎初始化完成
   - 确认系统托盘出现 Docker 图标

---

### 步骤 3: 安装 Git

1. **下载安装**
   ```powershell
   winget install --id Git.Git -e --source winget
   ```

2. **配置 Git（可选）**
   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "your.email@example.com"
   git config --global core.autocrlf false
   git config --global core.eol lf
   ```

---

### 步骤 4: 克隆项目代码

**选择你的分支策略：**

#### 方案 A: 直接使用官方仓库（推荐新手）

```powershell
cd E:\AI
git clone https://github.com/openclaw/openclaw.git
cd openclaw
```

#### 方案 B: Fork + 自定义分支（推荐开发者）

```powershell
# 1. Fork 到自己的 GitHub 账号
# 访问 https://github.com/openclaw/openclaw 点击 Fork

# 2. 克隆自己的 Fork
cd E:\AI
git clone https://github.com/YOUR_USERNAME/openclaw.git
cd openclaw

# 3. 添加上游仓库
git remote add upstream https://github.com/openclaw/openclaw.git

# 4. 创建自定义分支
git checkout -b PigClaw
```

---

### 步骤 5: 配置环境变量

**1. 复制示例配置：**

```powershell
Copy-Item .env.example .env
```

**2. 编辑 `.env` 文件：**

```powershell
notepad .env
```

**3. 修改关键配置项：**

```ini
# -----------------------------------------------------------------------------
# 网关配置
# -----------------------------------------------------------------------------
OPENCLAW_GATEWAY_TOKEN=你的网关令牌
OPENCLAW_GATEWAY_PORT=18789
OPENCLAW_BRIDGE_PORT=18790

# GitHub Token（用于技能安装等）
GITHUB_TOKEN="ghp_你的 token"

# -----------------------------------------------------------------------------
# 数据持久化路径
# -----------------------------------------------------------------------------
OPENCLAW_CONFIG_DIR=E:\AI\openclaw_docker\data
OPENCLAW_WORKSPACE_DIR=E:\AI\openclaw_docker\data\workspace
OPENCLAW_NODE_MODULES_DIR=E:\AI\openclaw_docker\data\node_modules

# -----------------------------------------------------------------------------
# 镜像配置
# -----------------------------------------------------------------------------
OPENCLAW_IMAGE=openclaw-with-go:local
```

**⚠️ 重要提示：**
- `OPENCLAW_GATEWAY_TOKEN`: 必须替换为你的真实 token
- `GITHUB_TOKEN`: 如需安装技能，必须配置
- 路径配置保持默认即可，容器会自动创建目录

---

### 步骤 6: 启动 Docker 容器

**1. 构建并启动：**

```powershell
# 首次启动（自动构建）
docker compose up -d --build

# 查看启动日志
docker compose logs -f
```

**2. 检查容器状态：**

```powershell
# 查看所有容器
docker compose ps

# 应该看到两个容器都处于 running 状态：
# openclaw-openclaw-gateway-1   running
# openclaw-openclaw-cli-1       running
```

**3. 常见问题：**

```powershell
# 如果容器启动失败，查看详细错误
docker compose logs openclaw-gateway

# 如果端口被占用，修改 .env 中的端口配置
# OPENCLAW_GATEWAY_PORT=18790  # 改为其他端口

# 强制重建容器
docker compose down
docker compose up -d --force-recreate
```

## 配置说明

### 核心配置文件

#### 1. `.env` - Docker 环境变量

**位置**: `E:\AI\openclaw_docker\.env`

**作用**: 控制 Docker 容器的运行参数

**关键配置项**:

| 配置项 | 说明 | 默认值 | 必填 |
|--------|------|--------|------|
| `OPENCLAW_GATEWAY_TOKEN` | Gateway 认证令牌 | - | ✅ |

| `OPENCLAW_BRIDGE_PORT` | Bridge 端口 | 18790 | ❌ |

| `OPENCLAW_CONFIG_DIR` | 配置持久化路径 | E:\AI\openclaw_docker\data | ❌ |
| `OPENCLAW_WORKSPACE_DIR` | 工作空间路径 | E:\AI\openclaw_docker\data\workspace | ❌ |
| `OPENCLAW_IMAGE` | Docker 镜像名称 | openclaw-with-go:local | ❌ |

**位置**: `E:\AI\openclaw_docker\data\openclaw.json`

**关键配置节**:

```json
      "groupPolicy": "allowlist",
      "tools": {
        "profile": "full",

      }
    }
  },
  "agents": {
    "defaults": {
```

## 故障排查

### 问题 1: 容器无法启动

**症状**: `docker compose up -d` 后容器立即退出

**诊断步骤：**

```powershell
# 1. 查看详细错误
docker compose logs openclaw-gateway

# 2. 检查 .env 配置
cat .env

# 3. 检查端口占用
netstat -ano | findstr :18789
```

**常见原因与解决：**

| 原因 | 解决方案 |
|------|----------|
| 端口被占用 | 修改 `.env` 中的 `OPENCLAW_GATEWAY_PORT` |
| 配置缺失 | 检查 `.env` 中 `OPENCLAW_GATEWAY_TOKEN` 是否填写 |
| 镜像损坏 | `docker compose pull` 重新拉取镜像 |
| 磁盘空间不足 | 清理磁盘后 `docker system prune` |

---

### 问题 2: Control UI 无法访问

**症状**: 浏览器访问 `http://localhost:18791/` 显示 ERR_EMPTY_RESPONSE

**诊断：**

```powershell
# 1. 检查 Browser Control 是否运行
docker compose logs openclaw-gateway | Select-String "Browser Control"

# 2. 检查端口映射
docker compose ps --format "table {{.Ports}}"

# 3. 测试端口连通性
Test-NetConnection localhost -Port 18791
```

**解决方案：**

1. **等待服务启动**（可能需要 1-2 分钟）
2. **检查防火墙**是否阻止了端口
3. **重启容器**：`docker compose restart`

---

### 问题 3: 飞书消息无响应

**症状**: 飞书机器人收不到消息或不回复

**诊断步骤：**

```powershell
# 1. 检查飞书插件状态
docker compose logs openclaw-gateway | Select-String "feishu"

# 2. 验证配置
docker compose exec openclaw-gateway bash -c "cat /home/node/.openclaw/openclaw.json | grep -A10 feishu"

# 3. 检查网络连接
docker compose exec openclaw-gateway bash -c "curl -I https://open.feishu.cn"
```

**常见原因：**

| 原因 | 解决方案 |
|------|----------|
| App Secret 错误 | 在飞书开放平台重新生成并更新 `openclaw.json` |
| 网络问题 | 检查代理配置或稍后重试 |
| 权限不足 | 确认飞书应用已发布且添加了必要权限 |

---

### 问题 4: Git Pull 失败

**症状**: `git pull` 超时或连接重置

**解决方案：**

```powershell
# 方案 1: 使用 HTTP 协议
git config url."http://github.com/".insteadOf "https://github.com/"
git pull upstream main

# 方案 2: 配置代理
export https_proxy=http://proxy-server:port
git pull upstream main

# 方案 3: 从 Gitee 镜像拉取
git remote add gitee https://gitee.com/mirrors/openclaw.git
git pull gitee main
```

---
